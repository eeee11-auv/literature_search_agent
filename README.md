# literature_search_agent
An LLM-powered literature research system that:

User Topic
   ↓
LLM Query Planning
   ↓
OpenAlex + Crossref
   ↓
Deduplication
   ↓
Rule-based Retrieval Ranking
   ↓
LLM Semantic Reranking
   ↓
Relevant Papers

Features

- LLM-based academic query expansion
- Multi-source literature retrieval
- Unified Paper data model
- DOI/title deduplication
- Two-stage ranking
- LLM relevance filtering
- API failure fallback
